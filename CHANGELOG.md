# Changelog

## 2026-09-16 — Platform expansion

Added authenticated project creation, content-addressed project file uploads with version metadata, persisted conversations and messages, server-side managed-model chat, model discovery, secure one-time API key creation/revocation, credit balance and idempotent ledger operations, job tracking, real image generation, explicit dataset consent controls, admin provider/model/feature registries, responsive workspace screens, deployment Dockerfile, Vessel deployment notes, and additional service invariant tests.

Known limitations remain documented in `docs/operations/PHASE_1_FOUNDATION_REPORT.md`: audio/video provider adapters, isolated code-agent workers, full billing/payment reconciliation, public HTTP API gateway, backup restore drills, and distributed queue execution require the next hardening phase.
